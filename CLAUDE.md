# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Язык

Документация, комментарии в коде и общение с пользователем — на русском языке.

## Что это

Скрипты синхронизации коллекций Bitwarden/Vaultwarden (тестировалось только с Vaultwarden) со структурой сервисов из БД Инвентаризации ([arms_inventory](https://github.com/spo0okie/arms_inventory)). Чистый PHP без composer, фреймворков и тестов; запуск вручную из консоли на Linux-хосте.

## Запуск

```bash
php ./sync.php    # синхронизация дерева сервисов Инвентаризации -> коллекции VW + ACL
php ./share.php   # обработка тегов #share:<путь> в notes элементов VW
```

Перед запуском нужен заполненный `config.priv.php` (в git он пустой; образец — `config.priv.sample.php`). Конфиг определяет глобальные переменные (`$webInventory`, `$inventoryAuth`, `$vwUrl`, `$vwLogin`, `$vwWebPassword`, `$vwCliPassword`) и константы `ORG_ID`, `COL_ROOT`. `$vwWebPassword` — это не пароль, а его hmac-sha-256 хэш (600000 итераций), вытаскивается из Chrome DevTools (запрос `token`, поле `password`).

Требуется Bitwarden CLI (`bw`), путь захардкожен в `bwApi::$cliPath` = `/usr/local/bin/bw`. Для self-hosted VW с непубличным сертификатом нужна NPM-версия CLI, а CA-сертификат должен быть в `/etc/ssl/certs/ca-certificates.crt` (путь тоже захардкожен в `cliExec`).

## Архитектура

Оба скрипта — плоские процедурные CLI-скрипты, использующие глобальные переменные `$bw` и `$inventory` и три библиотеки:

- **`lib_bwApi.php`** (`bwApi`) — работа с VW через **два канала одновременно**:
  - `bw` CLI через `proc_open` (`cliExec`) — списки/создание/изменение коллекций и элементов. JSON для записи прогоняется через `bw encode` и передаётся в stdin.
  - Web API через curl (`getReq`) — то, чего нет в CLI: список пользователей организации и ACL коллекций (`/collections/details`). Отсюда двойная авторизация: `init_session` логинится и в web API (токен), и в CLI (сессия).
  - Всё кэшируется в `$bw->cache` (`collections`, `users`, `items`); поиск — `findCollection`/`findUser` по фильтру. Кэш после записи **не** инвалидируется (строки перекэширования закомментированы).
- **`lib_inventoryApi.php`** (`inventoryApi`) — чтение сервисов из REST API Инвентаризации одним запросом (`cacheServices` с `expand=...Recursive`), дальше только работа с кэшем.
- **`lib_arrHelper.php`** (`arrHelper`) — статические хелперы поиска/фильтрации по массивам, ключевые: `getItemByFields`/`getItemsByFields` (поиск элементов по набору полей, с рекурсивным сравнением вложенных массивов).

### Соглашения о связке Инвентаризация ↔ VW

- Коллекция VW привязывается к сервису через `externalId = "inventory#<serviceID>"` — это единственный ключ соответствия.
- Имя коллекции — полный путь: `COL_ROOT/Родитель/Дочерний/...` (в VW у коллекций плоские полные имена, дерево VW строит сам). Путь собирает `serviceName()` рекурсией по `parent_id`.
- Команда сервиса = responsible + infrastructureResponsible + support + infrastructureSupport (все `*Recursive`), сопоставляется с пользователями VW по email (в нижнем регистре). Пользователи с `accessAll` (суперпользователи) в ACL не включаются.

### Логика sync.php

Рекурсивный обход дерева сервисов `parseService()` с корня. Если у сервиса нет команды в Инвентаризации или никого из команды нет в VW — коллекция не создаётся. Новые коллекции создаются без подтверждения (они пусты), а **изменение ACL существующей коллекции требует ручного подтверждения y/n**; подтверждённая строка изменения ACL передаётся вниз по ветке (`$authorizedAcl`), чтобы не спрашивать одно и то же для каждого потомка. Архивные сервисы пропускаются. Вывод — с ANSI-раскраской diff'а (красный «было» → зелёный «стало»).

### Логика share.php

Ищет в `notes` элементов строки `#share:<путь коллекции относительно COL_ROOT>`. Если коллекция найдена — добавляет её в `collectionIds` и удаляет строку-тег; при этом элемент **пересоздаётся** (createItem + deleteItem — новый получает другой ID), т.к. так пользователь может расшарить пароль в коллекцию, к которой сам не имеет доступа. Если коллекция не найдена — дописывает к тегу комментарий `//Коллекция не найдена`.
